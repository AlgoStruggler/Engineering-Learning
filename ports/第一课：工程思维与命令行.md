## 一、工程化

**工程化 = 让代码可维护、可协作、可部署、可迭代的一整套方法和工具**

## 二、命令行

### 1. **文件与目录**

```bash
pwd					 # 当前路径
ls -la				 # 列出文件，含隐藏文件
cd /path			 # 切换目录
mkdir -p a/b		 # 递归创建目录
cp -r src dst		 # 递归复制
mv src dst			 # 移动/重命名
rm -rf dir			 # 递归删除（危险）
touch file			 # 创建空文件
cat file			 # 查看文件
less file			 # 分页查看
head/tail -n 20 file # 查看头/尾
```

### 2. **查找与搜索**

```bash
find . -name "*.ts"  # 按名字查找
grep -rn "keyword" . # 递归搜索内容
which node           # 命令位置
```

### 3. **权限**

```bash
chmod +x script.sh    # 加执行权限
chmod 755 file        # rwxr-xr-x
chown user:group file # 改所有者
sudo command          # 以管理员执行
```

### 4. **进程与接口**

```bash
ps aux        # 所有进程
top / htop    # 实时监控
kill -9 PID   # 强杀进程
lsof -i :3000 # 查端口占用
netstat -tuln # 查看监听端口
```

### 5. **网络**

```bash
curl https://api.github.com   # 发请求
curl -X POST -d '{"a":1}' ... # POST
ping google.com               # 连通性
ssh user@host                 # 远程登录
scp file user@host:/path      # 远程复制
```

### 6. **环境变量**

```bash
echo $PATH       # 查看变量
export KEY=value # 设置变量
env              # 查看所有变量
```

### 7. **管道与重定向**

```bash
cat log.txt | grep error | wc -l # 管道
command > out.txt                # 覆盖输出
command >> out.txt               # 追加输出
command 2>&1                     # 合并错误输出
```

## 三、Git工作流

### 1. **基本概念**

* **工作区**：你看到的文件
* **暂存区**：`git add` 后的区域
* **本地仓库**：`git commit` 后的区域
* **远程仓库**：GitHub

### 2. **Git命令**

```bash
git status
git add .
git commit -m "feat: add login api"
git push origin main
git pull origin main
git branch feature/login
git checkout feature/login
git merge main
git rebase main
git log --oneline --graph
git diff
git stash
```

### 3. **工程化 Git 工作流**

标准流程：

1. 从 `main` 拉最新代码。
2. 新建 `feature branch`：`feature/login`。
3. 开发、`commit`。
4. `push` 到远程。
5. 开 `PR`（`Pull Request`）。
6. `Code Review`。
7. `merge` 回 `main`。
8. 删除 `branch`。

### 4. Commit Message 规范

用 `Conventional Commits`：

```text
feat: 新功能
fix: 修 bug
docs: 文档
style: 格式
refactor: 重构
test: 测试
chore: 构建/工具
```

### 5. 冲突解决

冲突不可怕，流程是：

1. `git pull` 或 `git merge` 出现冲突。
2. 打开冲突文件，看到 `<<<<<<<`、`=======`、`>>>>>>>`。
3. 手动决定保留哪部分。
4. `git add` 标记已解决。
5. `git commit` 完成合并。

## 四、真实场景：一个功能从开发到上线

场景：给项目加一个“用户登录”功能。

```bash
# 1. 拉最新代码
git checkout main
git pull origin main

# 2. 新建分支
git checkout -b feature/login

# 3. 开发，查看状态
git status

# 4. 添加并提交
git add .
git commit -m "feat: add login api and form"

# 5. 推送
git push origin feature/login

# 6. 在 GitHub 开 PR，review，merge

# 7. 回到 main，拉最新
git checkout main
git pull origin main

# 8. 删除本地分支
git branch -d feature/login
```

这中间会用到：

- 命令行创建文件、编辑、运行。
- 查看日志、排查错误。
- 环境变量配置数据库连接。
- `Docker` 启动数据库。
